Strata Market Schematics

Seven mainnet markets at a glance. Same shape every time — two tranches into a CDO, a CDO into one strategy, a strategy into an external protocol — with the withdrawal cooldowns drawn in blue underneath so you can see at a glance which rails each market actually has.

None of the seven is multi-strategy

Every live strategy inherits the single Strategy base and holds one external position. Across all deployment files on all five networks there are 8 CDOs and 8 strategy contracts — a strict one-to-one. MultiStrategy and its only child IsolatedStrategy appear in no deployment file; that topology is drawn last, for contrast.

The three cooldown rails

SharesCooldown
Locks vault shares on redeem, with lock and fee tiers by coverage. Attached to the CDO via setSharesCooldown().
ERC20Cooldown
Siloes the payout token for a per-tranche period, then releases it. Attached to the strategy at init.
UnstakeCooldown
Clones a per-user request proxy that queues in the external protocol. Attached to the strategy, and only live if a request implementation is registered for the token.

What a multi-strategy market looks like

spkMhyperIso is the only market configured as multi-strategy. It has a complete deployment class and fork tests but appears in no deployment file, so nothing below is live.

What the tranches change in this setup

Deployment
Identical — ensureTranches() is not overridden, both tranches are USDC-denominated ERC-4626 vaults initialized against the CDO, and the CDO is still bound by one configure(accounting, strategy, jrt, srt). Only the naming differs: this is the one market whose two tranches are named after different assets (jrIsoSpk / srIsoMHYPER), one per leg.
Ordering
MultiStrategy_init() requires cdo.accounting() == address(0), so the parent must be initialized before cdo.configure() binds the tranches. The standard deploy order already satisfies this, but it is the only market where that sequence is enforced on-chain.
Tranche identity
Sub-strategies are initialized with the IsolatedStrategy as their CDO, so when a leg calls cdo.isJrt(tranche) to pick its cooldown period it hits the parent, which forwards to the real CDO. Tranche identity therefore travels two hops instead of one.
Per-leg controls
perStrategyTokens carries four pause flags per leg and token — jrtDeposits, srtDeposits, jrtWithdrawals, srtWithdrawals. A tranche can be halted on one leg while still trading on the other, which no single-strategy market can express.

Five markets run all three rails. Ethena has no share-level cooldown at all; nestopal has an UnstakeCooldown proxy with no request implementation and a strategy that never receives its address, so only two rails can fire. The unlaunched isolated market is the only one where a rail is wired to some but not all of the strategy code behind a single CDO.
